## Projeto em destaque

### [Poker MTT BI](https://github.com/yancamargo988-afk/poker-mtt-bi-showcase)

BI pessoal que uso todos os dias. Tem métricas, o financeiro completo do time e um **assistente com LLM local** que responde em português sobre os meus números.

- **O modelo traduz, o código responde:** o LLM gera uma consulta estruturada (tool calling) e o C# calcula. Nenhum número passa pelo modelo.
- **Modelo escolhido por medição:** 7 modelos de 5 fabricantes num corpus de casos reais.
- **Escrita segura:** travas determinísticas e "só o clique grava". Hoje são 54/57 lançamentos certos e 0 gravação errada.
- **Desenvolvido com agentes de IA:** spec, plano, worktrees isoladas e revisão independente antes de cada merge. São +1.800 testes.

`C#` `.NET 10` `React 19` `TypeScript` `SQLite` `Ollama` · *código privado, vitrine pública*
