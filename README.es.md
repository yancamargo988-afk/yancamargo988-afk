## Proyecto destacado

### [Poker MTT BI](https://github.com/yancamargo988-afk/poker-mtt-bi-showcase/blob/main/README.es.md)

BI personal que uso todos los días. Tiene métricas, las finanzas completas del equipo y un **asistente con LLM local** que responde sobre mis números en lenguaje natural.

- **El modelo traduce, el código responde:** el LLM genera una consulta estructurada (tool calling) y C# calcula. Ningún número pasa por el modelo.
- **Modelo elegido por medición:** 7 modelos de 5 fabricantes, probados con un corpus de casos reales.
- **Escritura segura:** travas deterministas y "solo el clic guarda". Hoy acierta 54/57 registros, con 0 escrituras erróneas.
- **Desarrollado con agentes de IA:** spec, plan, worktrees aislados y revisión independiente antes de cada merge. Tiene +1.800 pruebas.

`C#` `.NET 10` `React 19` `TypeScript` `SQLite` `Ollama` · *código privado, vitrina pública*
